# Felicitá Balões - Site Institucional

Site institucional em React para a empresa **Felicitá Balões**, totalmente front-end, criado com **Vite + React**.

## Rodando o projeto

```bash
npm install
npm run dev
```

Depois acesse o endereço informado pelo Vite (por padrão `http://localhost:5173`).

## Estrutura principal

- `src/data/config.js`: todas as informações configuráveis (nome, slogan, contatos, serviços, imagens, etc).
- `src/components/*`: componentes funcionais com React Hooks para cada seção.
- `src/App.jsx`: estrutura de seções e botão flutuante do WhatsApp.

Para trocar textos, serviços, imagens ou links, edite apenas o arquivo `src/data/config.js`.
